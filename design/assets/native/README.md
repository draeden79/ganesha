# Assets legítimos do Ganesha Desktop

Copiados byte a byte de `/Applications/Ganesha.app/Contents/Resources/app.asar`, aplicativo `ai.omganesha.app`, após inspeção real da janela autorizada pelo usuário. Não foram gerados novamente nem recoloridos.

- `icon-symbol-DQ7Exn6W.png`: logo do elefante usado na marca.
- `ganesha-journey-wave-C0jV_k0n.png`: mascote; uso pequeno no botão de dicas locais, sem sugerir chat de IA integrado.
- `figtree-latin-wght-normal-D_ZTVpCC.woff2`, `figtree-latin-ext-wght-normal-DCwSJGxG.woff2`: fontesFigtree existentes no desktop. LicençaOFL em `FIGTREE-LICENSE.txt`, fornecida pelo pacoteFigtree instalado no projeto do Construtor.

Capturas do aplicativo estão em `design/reference/`; são evidência de design, não assets de conteúdo do aluno. O Construtor pode copiar logo/mascote a `public/` e manter as fontes locais já instaladas no app.
