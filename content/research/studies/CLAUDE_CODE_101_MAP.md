# Claude Code 101 — mapa de consumo e uso pedagógico

Observado em 28/09/2026. As 12 aulas do curso têm texto público integralmente estudado. Dez transcrições oficiais foram lidas; a página Skills não exibe rótulo de transcrição e Code review foi estudada como texto com exercícios interativos. **Nenhum vídeo recebeu certificação audiovisual integral.** O quiz e a emissão de badge exigem login e permanecem com acesso bloqueado, sem resposta ou certificação em nome de uma pessoa.

Este mapa organiza fichas existentes; não é uma nova leitura nem uma nova aula do Ganesha. A conclusão textual das 12 aulas não significa conclusão de todo o curso multimídia, nem de toda a Academy.

| Ordem | Aula e ficha local | Contribuição para o Educador | Limite principal |
|---|---|---|---|
| 1 | [What is Claude Code?](backfill/academy-02/what-is-claude-code.md) | Distinguir pedido, ação e evidência de resultado. | Apresentação conceitual sem prática executada nesta pesquisa. |
| 2 | [How Claude Code works](backfill/academy-02/how-claude-code-works.md) | Explicar o ciclo de obtenção de contexto, ação e avaliação. | O ciclo descrito não garante correção. |
| 3 | [Installing Claude Code](backfill/academy-06/installing.md) | Reconhecer interface, conta e projeto; conferir dependências visíveis. | Cinco superfícies descritas; nenhuma instalação realizada. |
| 4 | [Your first prompt](backfill/academy-01/first-prompt.md) | Fornecer contexto e um resultado observável. | Atalhos/estados de terminal não se transferem automaticamente ao Desktop. |
| 5 | [Explore → Plan → Code → Commit](official/claude-explore-plan-code-commit.md) | Separar as fases; L01 termina no plano revisado. | Há imagem parcial do fluxo; vídeo e outras imagens continuam pendentes. |
