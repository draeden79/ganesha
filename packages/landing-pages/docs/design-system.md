# Ganesha design system — approved baseline

This is the permanent visual standard for the project. The original landing page was approved on 2026-09-28. Reuse its composition, typography and visual restraint across new courses. English is the default language.

| Token | Value | Use |
| --- | --- | --- |
| White | #FDFDFC | Primary canvas |
| Cream | #FBFAF8 | Quiet section background |
| Lavender | #F5F3FB | Learning surfaces and illustrations |
| Purple | #6C3BEE | Primary action and emphasis |
| Ink | #17151F | Primary text |
| Muted | #706C7A | Supporting text |
| Border | #E9E6EF | Subtle separators |
| Font | Figtree | All interface and editorial text |

Strong headlines, clear hierarchy, generous whitespace, consistent alignment, softly rounded corners, discreet borders and delicate shadows. Purple should guide attention. Gold belongs only in small illustration details. Use main body text of at least 16px and practical mobile tap targets. Respect reduced motion and visible keyboard focus.

Use the approved split hero and arched illustration, a quiet course overview, benefits, an expandable curriculum, audience guidance, FAQ and closing call to action. Omit claims and sections that cannot be supported by the brief. The phase-one CTA explores the curriculum; it does not pretend to enroll or charge the visitor.
